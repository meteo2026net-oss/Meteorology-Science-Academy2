# أكاديمية علوم الأرصاد الجوية

منصة تعليمية عربية لإعداد وتأليف ونشر دروس علوم الأرصاد الجوية، مع مسارات تأسيسية في الرياضيات والفيزياء، واختبارات ومختبرات ومحاكاة تعليمية.

## صفحات المنصة

- `index.html` — الصفحة الرئيسية والمكتبة التعليمية.
- `lesson.html` — عارض الدروس المنشورة مع تسجيل إكمال الدرس في حساب الطالب.
- `account.html` — بوابة تسجيل الدخول وسجل الاختبارات والتقدم الدراسي.
- `exams.html` — مركز الاختبارات والتصحيح المركزي وسجل المحاولات والشهادات.
- `exam-studio.html` — استوديو المدير لإدارة بنك الأسئلة وإنشاء نماذج الاختبارات.
- `verify-certificate.html` — صفحة عامة للتحقق من رمز الشهادة دون كشف بيانات الحساب.
- `labs.html` — المختبرات العلمية والمحاكاة التعليمية.
- `editor.html` — استوديو تأليف الدروس وكتل المحتوى.
- `preview.html` — معاينة محلية للمسودة قبل نشرها.
- `hierarchy.html` — إدارة الفصول والوحدات وربط الدروس.
- `admin.html` — إدارة المقررات والدروس.
- `content-review.html` — مراجعة المسودات ومعاينتها ونشر مجموعة مختارة بعد التأكيد.
- `students.html` — إحصاءات الطلاب والإنجازات ونتائج الاختبارات؛ للمدير فقط.
- `diagnostics.html` — فحص اتصال قاعدة البيانات والجداول والمخزن؛ للمدير فقط.

## البنية التقنية

- واجهة ويب عربية RTL باستخدام HTML وCSS وJavaScript Modules.
- Supabase Auth لإدارة حسابات الطلاب والمديرين.
- PostgreSQL لتخزين المقررات والدروس والفصول والوحدات والتقدم ومحاولات الاختبار.
- Supabase Storage للملفات التعليمية.
- Row Level Security (RLS) لحماية بيانات الطلاب وحصر إدارة المحتوى بالمدير.
- مكتبة Supabase JS مثبتة على إصدار CDN محدد في الصفحات.

## إعداد Supabase

1. تأكد من أن مشروع Supabase نشط.
2. راجع ونفّذ `supabase/schema.sql`.
3. نفّذ `supabase/content_cms.sql` لإضافة حقول إدارة المحتوى.
4. نفّذ `supabase/hierarchy.sql` لإنشاء هيكل الفصول والوحدات.
5. نفّذ `supabase/storage.sql` لإنشاء مخزن الملفات وسياسات الوصول.
6. نفّذ `supabase/exam_certification.sql` لإنشاء بنك الأسئلة الخاص ومحرك التصحيح المركزي والشهادات.
7. نفّذ `supabase/exam_security_hardening.sql` لتأمين واجهات التصحيح والتحقق من الشهادات.
8. نفّذ `supabase/exam_studio.sql` لإضافة أدوات تأليف الأسئلة ونماذج الاختبارات.
9. ضع رابط المشروع ومفتاح Publishable في `supabase-config.js`. لا تضع مفتاح `service_role` أو أي مفتاح سري في ملفات المتصفح.
10. أنشئ حساب المسؤول من `account.html`، وأكمل تأكيد البريد إذا كان مفعلاً.
11. بعد إنشاء الحساب، استبدل البريد في `supabase/bootstrap_admin.sql` بالبريد الفعلي، ثم نفّذ الملف يدوياً من SQL Editor بصلاحية موثوقة.
12. سجّل الدخول من `admin.html` أو `editor.html` لبدء إدارة المحتوى، وافتح `exam-studio.html` لإدارة بنك الأسئلة.

لا تمنح حساباً دور المدير عبر واجهة عامة. ترقية الدور عملية إدارية موثوقة فقط.

## سير نشر المحتوى

1. أنشئ الدرس أو حرّره من استوديو التأليف.
2. استخدم المعاينة المحلية لمراجعة المحتوى.
3. افتح `content-review.html` لمراجعة المسودات.
4. حدد الدروس التي اكتملت مراجعتها العلمية والتحريرية فقط، ثم انشرها.
5. تأكد من نشر المقرر نفسه من لوحة الإدارة؛ نشر الدروس وحدها لا يجعلها مرئية إذا بقي المقرر مسودة.

## حفظ التقدم والاختبارات

- يتطلب حفظ التقدم تسجيل دخول الطالب.
- زر «إكمال الدرس» يحفظ حالة الإكمال في `academy_lesson_progress`.
- الاختبارات المركزية تتطلب تسجيل الدخول؛ تُجلب الأسئلة من `get_academy_exam_questions` دون مفاتيح الإجابة.
- يُرسل الطالب اختياراته فقط إلى `submit_academy_exam`، ويجري PostgreSQL التصحيح وحساب النتيجة وحفظ المحاولة.
- لا يملك المتصفح صلاحية إدخال أو تعديل محاولات الاختبار مباشرة، ولا يستطيع قراءة بنك الإجابات الخاص.
- تُصدر شهادة داخلية تلقائياً عند اجتياز اختبار مسار الرياضيات أو الفيزياء بنسبة 70% فأكثر، وترتبط بمحاولة محفوظة في قاعدة البيانات.
- تعرض بوابة الطالب الشهادات، وتعرض لوحة المدير عدد الشهادات لكل الأكاديمية ولكل طالب.
- يستطيع الطالب قراءة تقدمه ونتائجه فقط، بينما تعرض لوحة `students.html` البيانات الإجمالية للمدير بعد التحقق من الدور وسياسات RLS.
- الشهادات تعليمية داخلية ولا تمثل اعتماداً أكاديمياً أو مهنياً رسمياً.
- تبقى بعض أدوات التعلم الذاتي المحلية قابلة للاستخدام دون حساب، لكن الاختبارات المركزية والشهادات لا تعمل دون جلسة مستخدم.

## التشغيل والنشر

يمكن تشغيل المشروع محلياً عبر خادم ثابت مثل VS Code Live Server أو عبر GitHub Codespaces. لا تعتمد على فتح ملفات HTML مباشرة عند استخدام ES Modules أو مكتبات CDN.

للنشر الثابت يمكن استخدام Netlify أو GitHub Pages. تأكد من ضبط مجلد النشر على جذر المستودع، ومن أن إعدادات Supabase وRedirect URLs تسمح بنطاق الموقع المنشور.

## تنبيهات

- محتوى المحاكاة التعليمية لا يُستخدم بديلاً عن أدوات الرصد أو التنبؤ التشغيلي.
- الشهادات الحالية شهادات إتمام داخلية وليست اعتماداً أكاديمياً أو مهنياً رسمياً.
- لا تنشر محتوى علمياً قبل مراجعته، ولا تنشر المقرر قبل التأكد من جاهزية دروسه.
- لا تُضمّن كلمات مرور أو مفاتيح سرية أو بيانات حسابات في GitHub.
