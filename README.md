# أكاديمية علوم الأرصاد الجوية | Meteorology Science Academy

منصة عربية تفاعلية للتعلم الذاتي في الرياضيات والفيزياء وتطبيقاتهما في علوم الغلاف الجوي.

## تشغيل المنصة
- افتح [الأكاديمية](./index.html) محلياً في متصفح حديث.
- افتح [المختبرات الجوية الافتراضية](./labs.html) لإجراء التجارب التفاعلية.
- افتح [مركز الاختبارات والتقييم](./exams.html) لخوض الاختبارات ومراجعة النتائج.
- افتح [استوديو تأليف الدروس](./editor.html) لإنشاء المواد والفصول والدروس وإدارة محتواها.\n- افتح [عارض الدروس](./lesson.html) لعرض الدروس المنشورة عبر رابط المادة والدرس.
- تعمل الدروس والمختبرات والاختبارات محلياً دون خادم. تتطلب الحسابات والمزامنة المركزية تفعيل Supabase وتطبيق مخطط قاعدة البيانات.

## استوديو تأليف المواد والدروس\n- `editor.html` — محرر مرئي لإنشاء المواد والدروس وترتيب وحدات المحتوى دون كتابة JSON يدوياً.\n- يدعم كتل الشرح والعناوين والمعادلات والأمثلة والصور والفيديو والملاحظات والقوائم وأسئلة المراجعة.\n- `lesson.html` — عارض عام للدروس المنشورة مع الأهداف التعليمية والاختبارات القصيرة.\n- `supabase/content_cms.sql` — ترقية إضافية آمنة لإضافة بيانات المستوى والمدة والأهداف التعليمية.\n- `supabase/storage.sql` — إنشاء مساحة تخزين للصور والملفات التعليمية بسياسات قراءة عامة ورفع/تعديل/حذف للمدير فقط.\n- `supabase-config.js` — ملف إعداد عام؛ ضع فيه رابط Supabase ومفتاح Publishable ليتمكن زوار الموقع من فتح الدروس المنشورة. هذا المفتاح مخصص للمتصفح وتظل الحماية عبر RLS.\n- يتطلب الحفظ والنشر اتصال Supabase نشطاً وحساب مدير. تستخدم الصفحات مفتاح Publishable فقط مع سياسات RLS.\n\n## محتويات الإصدار 1.4
- واجهة عربية متجاوبة (RTL).
- مسار رياضيات من 12 وحدة ومسار فيزياء من 12 وحدة.
- شرح للمفاهيم وأمثلة مرتبطة بالأرصاد الجوية.
- أسئلة اختيار من متعدد مع تصحيح وتفسير.
- حفظ تقدم الطالب محلياً عبر المتصفح، مع استيراد وتصدير JSON.
- مختبر ضغط الهواء مع الارتفاع.
- مختبر الرطوبة النسبية ودرجة الندى.
- مختبر تحليل متجه الرياح إلى مركبتين شرقية وشمالية.
- بنك اختبارات مستقل للرياضيات والفيزياء، مع مستويات أساسية ومتوسطة ومتقدمة.
- اختبارات عشوائية من 10 أو 15 أو 20 سؤالاً، وتصحيح آلي بعد التسليم مع شرح الإجابات.
- سجل نتائج محلي، ومراجعة كاملة للأسئلة، وشهادة إتمام داخلية قابلة للطباعة عند تحقيق 70% لمسار منفرد.
- بوابة حساب طالب باستخدام Supabase Auth، مع مزامنة نتائج الاختبارات للمستخدم المسجل.
- مخطط PostgreSQL أولي في `supabase/schema.sql` يتضمن الملفات الشخصية والدروس والتقدم والاختبارات وسياسات RLS.

## تفعيل الحسابات وقاعدة البيانات
1. استعد مشروع Supabase المرتبط بالأكاديمية إذا كان متوقفاً.
2. افتح SQL Editor في مشروع Supabase وراجع ثم نفّذ `supabase/schema.sql`.
3. من إعدادات API انسخ رابط المشروع ومفتاح Publishable فقط.\n4. ضع القيمتين في `supabase-config.js` ثم ارفع التعديل إلى GitHub. هذا الملف عام بطبيعته؛ لا تضع فيه أي Secret.\n5. افتح `editor.html` وسجّل الدخول بحساب مدير لإنشاء المواد والدروس.
6. افتح صفحات الإدارة وسجّل الدخول عند الحاجة.
7. لا تضع مفتاح `service_role` أو أي Secret في ملفات المتصفح أو GitHub.
8. لمنح أول حساب صلاحية مدير، استخدم SQL موثوقاً في لوحة Supabase بعد التأكد من بريد الحساب، ولا تسمح للطلاب بتغيير دورهم بأنفسهم.

> حالة الربط عند إصدار هذا التحديث: مشروع Supabase المرتبط موجود لكنه غير نشط (INACTIVE)، ولم يتم تطبيق المخطط عليه بعد. لذلك بوابة الحساب جاهزة برمجياً لكنها لن تعمل فعلياً حتى استعادة المشروع وتطبيق المخطط وإدخال مفتاح Publishable.

## ملاحظات علمية وتقنية
- المختبرات نماذج تعليمية مبسطة وليست أدوات تشغيلية للتنبؤ.
- نموذج الضغط يستخدم تقريباً أُسّياً تعليمياً ولا يمثل البنية الحرارية الكاملة للغلاف الجوي.
- حساب الرطوبة يستخدم تقريب Magnus.
- اتجاه متجه الرياح في المختبر يعني اتجاه الحركة (إلى أين تتجه)، وليس اصطلاح الأرصاد الذي يصف الجهة التي تأتي منها الرياح.
- التقدم محفوظ في المتصفح الحالي فقط. تصدير JSON يسمح بنقله يدوياً إلى جهاز آخر.
- المحتوى تأسيسي قابل للتوسع، ولا يمثل اعتماداً أكاديمياً رسمياً.

## إدارة المحتوى التعليمي\n- `editor.html` — محرر المحتوى العلمي والمواد والدروس.\n- `lesson.html` — عارض المحتوى المنشور.\n- `supabase/content_cms.sql` — ترقية مخطط المحتوى.\n- `supabase/storage.sql` — إعداد تخزين ملفات المحتوى.\n\n## لوحة الإدارة
- `admin.html` — لوحة مدير محمية بصلاحيات Supabase، لإدارة المقررات والدروس ومراجعة حسابات الطلاب ونتائج الاختبارات.
- `supabase/bootstrap_admin.sql` — إجراء يدوي لمنح أول حساب موثوق دور مدير. استبدل البريد التجريبي قبل التنفيذ، ونفّذه من SQL Editor فقط.
