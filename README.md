# أكاديمية علوم الأرصاد الجوية | Meteorology Science Academy

منصة عربية تفاعلية للتعلم الذاتي في الرياضيات والفيزياء وتطبيقاتهما في علوم الغلاف الجوي.

## تشغيل المنصة
- افتح [الأكاديمية](./index.html) محلياً في متصفح حديث.
- افتح [المختبرات الجوية الافتراضية](./labs.html) لإجراء التجارب التفاعلية.
- افتح [مركز الاختبارات والتقييم](./exams.html) لخوض الاختبارات ومراجعة النتائج.\n- افتح [بوابة الطالب](./account.html) لتسجيل الدخول وعرض النتائج المركزية عند تفعيل Supabase.
- تعمل الدروس والمختبرات والاختبارات محلياً دون خادم. تتطلب الحسابات والمزامنة المركزية تفعيل Supabase وتطبيق مخطط قاعدة البيانات.

## محتويات الإصدار 1.3
- واجهة عربية متجاوبة (RTL).
- مسار رياضيات من 12 وحدة ومسار فيزياء من 12 وحدة.
- شرح للمفاهيم وأمثلة مرتبطة بالأرصاد الجوية.
- أسئلة اختيار من متعدد مع تصحيح وتفسير.
- حفظ تقدم الطالب محلياً عبر المتصفح، مع استيراد وتصدير JSON.
- مختبر ضغط الهواء مع الارتفاع.
- مختبر الرطوبة النسبية ودرجة الندى.
- مختبر تحليل متجه الرياح إلى مركبتين شرقية وشمالية.
- بنك اختبارات مستقل للرياضيات والفيزياء، مع مستويات أساسية ومتوسطة ومتقدمة.
- اختبارات عشوائية من 10 أو 15 أو 20 سؤالاً، وتصحيح آلي بعد التسليم مع شرح الإجابات.
- سجل نتائج محلي، ومراجعة كاملة للأسئلة، وشهادة إتمام داخلية قابلة للطباعة عند تحقيق 70% لمسار منفرد.\n- بوابة حساب طالب باستخدام Supabase Auth، مع مزامنة نتائج الاختبارات للمستخدم المسجل.\n- مخطط PostgreSQL أولي في `supabase/schema.sql` يتضمن الملفات الشخصية والدروس والتقدم والاختبارات وسياسات RLS.

## تفعيل الحسابات وقاعدة البيانات\n1. استعد مشروع Supabase المرتبط بالأكاديمية إذا كان متوقفاً.\n2. افتح SQL Editor في مشروع Supabase وراجع ثم نفّذ `supabase/schema.sql`.\n3. من إعدادات API انسخ رابط المشروع ومفتاح Publishable فقط.\n4. افتح `account.html`، وأدخل القيمتين واحفظ الإعدادات.\n5. لا تضع مفتاح `service_role` أو أي Secret في ملفات المتصفح أو GitHub.\n6. لمنح أول حساب صلاحية مدير، استخدم SQL موثوقاً في لوحة Supabase بعد التأكد من بريد الحساب، ولا تسمح للطلاب بتغيير دورهم بأنفسهم.\n\n> حالة الربط عند إصدار هذا التحديث: مشروع Supabase المرتبط موجود لكنه غير نشط (INACTIVE)، ولم يتم تطبيق المخطط عليه بعد. لذلك بوابة الحساب جاهزة برمجياً لكنها لن تعمل فعلياً حتى استعادة المشروع وتطبيق المخطط وإدخال مفتاح Publishable.\n\n## النشر عبر GitHub Pages
1. افتح Settings في المستودع.
2. اختر Pages من القائمة.
3. في Build and deployment اختر Deploy from a branch.
4. اختر الفرع main والمجلد /(root)، ثم Save.
5. بعد اكتمال النشر سيكون الرابط عادة:
   https://meteo2026net-oss.github.io/Meteorology-Science-Academy2/

## ملاحظات علمية وتقنية
- المختبرات نماذج تعليمية مبسطة وليست أدوات تشغيلية للتنبؤ.
- نموذج الضغط يستخدم تقريباً أُسّياً تعليمياً ولا يمثل البنية الحرارية الكاملة للغلاف الجوي.
- حساب الرطوبة يستخدم تقريب Magnus.
- اتجاه متجه الرياح في المختبر يعني اتجاه الحركة (إلى أين تتجه)، وليس اصطلاح الأرصاد الذي يصف الجهة التي تأتي منها الرياح.
- التقدم محفوظ في المتصفح الحالي فقط. تصدير JSON يسمح بنقله يدوياً إلى جهاز آخر.
- المحتوى تأسيسي قابل للتوسع، ولا يمثل اعتماداً أكاديمياً رسمياً.
