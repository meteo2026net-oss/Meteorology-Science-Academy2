# أكاديمية علوم الأرصاد الجوية

منصة تعليمية عربية لبناء مكتبة مواد وفصول ودروس في الرياضيات والفيزياء وعلوم الأرصاد الجوية.

## صفحات المحتوى

- `index.html` — مكتبة الأكاديمية والمواد التعليمية.
- `editor.html` — استوديو إنشاء المواد والدروس وإدارة كتل المحتوى.
- `preview.html` — معاينة محلية للمسودة قبل النشر، دون الحاجة إلى حفظها في قاعدة البيانات.
- `lesson.html` — عارض الدروس المنشورة.
- `labs.html` — مختبرات علمية تعليمية.

## أنواع المحتوى في المحرر

- عناوين وشروحات وملاحظات وقوائم.
- معادلات LaTeX بواسطة KaTeX.
- أمثلة محلولة.
- صور وفيديوهات وروابط ملفات.
- تنظيم الدروس ضمن فصول ووحدات، مع ترتيب مستقل للدروس.
- جداول علمية قابلة للتحرير.
- رسوم بيانية من نقاط X,Y.
- محاكاة تعليمية للضغط الجوي مع الارتفاع.
- أسئلة مراجعة قصيرة داخل الدرس.

## تشغيل محلي

يمكن فتح `index.html` و`preview.html` مباشرة. لا تتطلب المعاينة المحلية قاعدة بيانات. للحصول على تجربة موثوقة عند استخدام وحدات ES Modules أو استيراد مكتبات CDN، شغّل خادماً محلياً بسيطاً مثل Live Server.

## إعداد Supabase للحفظ والنشر

1. استعد مشروع Supabase المرتبط بالأكاديمية أو أنشئ مشروعاً نشطاً.
2. راجع ونفّذ `supabase/schema.sql` أولاً.
3. نفّذ `supabase/content_cms.sql` لإضافة حقول المستوى والمدة والأهداف.
4. نفّذ `supabase/storage.sql` لإنشاء مساحة ملفات المحتوى.
5. ضع رابط المشروع ومفتاح Publishable في `supabase-config.js`. لا تضع مفتاح service_role أو أي سر في ملفات المتصفح.
6. افتح `editor.html`، سجّل الدخول بحساب مدير المحتوى، ثم أنشئ المواد والدروس.

تُقيّد سياسات RLS عمليات إدارة المحتوى ورفع الملفات بحساب مدير. القراءة العامة تقتصر على المحتوى المنشور وفق سياسات المخطط. مساحة التخزين العامة تتيح قراءة الملفات الموجودة في bucket المخصص فقط.

## ملاحظات

- المعاينة في `preview.html` محلية على المتصفح الحالي وتقرأ مسودة المحرر من localStorage.
- حقول الفصل والوحدة أضيفت إلى `academy_lessons` عبر migration المحتوى؛ نفّذ `content_cms.sql` قبل حفظ الدروس الجديدة.
- الحفظ والنشر ورفع الملفات تتطلب مشروع Supabase نشطاً، ومخططاً مطبقاً، ومفتاح Publishable صحيحاً.
- محاكاة الضغط والارتفاع نموذج تعليمي مبسط وليست أداة رصد أو تنبؤ تشغيلي.
- لا يتم تضمين بيانات اعتماد إدارية أو مفاتيح سرية في المستودع.
- صفحات الحسابات والاختبارات القديمة ليست جزءاً من مسار تطوير محرر المحتوى الحالي.

## النشر عبر GitHub Pages

من إعدادات المستودع افتح **Settings → Pages**، واختر النشر من الفرع `main` والمجلد الجذر. لا تعتبر الصفحة منشورة حتى يؤكد GitHub اكتمال النشر.
